LA0200
======

106-Key JIS Realforce R1 Keyboard.

DESCRIPTION
-----------

The Realforce LA0200 (marketing name Realforce 106S) is a standard fullsize WKL 106-Key JIS Realforce. It is very similar to it's predecessor, the LA0100, the only difference between them being the dome weighting (LA0100 is variable weight, whereas LA0200 is uniform 30g). It was released in January of 2003.

ND0100

89-Key Realforce R1 Keyboard.

DESCRIPTION

The Realforce ND0100 is a standard WKL/TKL 89-Key Realforce. It was produced starting in October of 2003. As with many Realforces from this period, it uses variable weight domes. The colour scheme is the standard beige Realforce case and two-tone beige/ivory keycaps. Because this is an early model, it uses the older blue Realforce logo, and a PS/2 connector.
